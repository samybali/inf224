Detailed Description

Represents a movie with chapters.

The Film class inherits from Video and adds chapter management (duration of each chapter) using a dynamic array of integers. It implements the "Rule of Three" (Copy Constructor, Assignment Operator, Destructor) to ensure proper memory management for the dynamically allocated array.
