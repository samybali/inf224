Detailed Description

Represents a video object with a duration.

This class inherits from Multimedia and adds a length attribute (duration). It overrides the display() and play() methods to handle specific video behaviors.

Note: The constructor is protected to enforce the Factory design pattern. Instances of Video should be created via the Manager class.
