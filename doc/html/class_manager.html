Detailed Description

Central class that manages all Multimedia objects and Groups.

The Manager acts as a factory to create objects (Photo, Video, Film, Group) and as a database to store them using std::map containers. It ensures the consistency of the data (e.g., preventing duplicate names) and handles interactions such as displaying, playing, or removing items.
