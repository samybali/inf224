\doxysubsection{Detailed Description}
Represents a video object with a duration. 

This class inherits from \doxylink{class_multimedia}{Multimedia} and adds a length attribute (duration). It overrides the \doxylink{class_video_a3d598fde1227ad5c7c55d48f80796741}{display()} and \doxylink{class_video_a89e11497f4f200f387805b10bd42922d}{play()} methods to handle specific video behaviors.

Note:\+ The constructor is protected to enforce the Factory design pattern. Instances of \doxylink{class_video}{Video} should be created via the \doxylink{class_manager}{Manager} class.
