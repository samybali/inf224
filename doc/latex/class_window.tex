\doxysubsection{Detailed Description}
The main GUI frame for the Remote Control Application. 

This class inherits from JFrame and provides a graphical user interface to interact with the C++ \doxylink{class_multimedia}{Multimedia} Server. It includes a text area to display server responses, a menu bar, and a toolbar. It uses the \doxylink{class_client}{Client} class to establish a TCP connection.
