\doxysubsection{Detailed Description}
Custom exception class for errors occurring within the \doxylink{class_manager}{Manager}. 

Inherits from std::\+runtime\+\_\+error. Used to report logical errors (e.\+g., duplicate names, objects not found) or invalid arguments during the execution of \doxylink{class_manager}{Manager} methods.
