\doxysubsection{Detailed Description}
Abstract base class representing a generic multimedia object. 

This class holds the common attributes (name, file path) for all media types. It is an abstract class because the \doxylink{class_multimedia_a1fa4ae371afc516559955b38e0392acb}{play()} method is pure virtual. It provides the interface that specific classes like \doxylink{class_photo}{Photo} or \doxylink{class_video}{Video} must implement.
