\doxysubsection{Detailed Description}
Represents a photo object with geolocation coordinates. 

This class inherits from \doxylink{class_multimedia}{Multimedia} and adds latitude and longitude attributes. It overrides the \doxylink{class_photo_aadadd5b67b9ca1e801db7b6e4c1b5e74}{display()} and \doxylink{class_photo_a98b55224b5f9bd016cb08aa2e9a64e46}{play()} methods to handle specific photo behaviors.

Note:\+ The constructor is protected to enforce the Factory design pattern. Instances of \doxylink{class_photo}{Photo} should be created via the \doxylink{class_manager}{Manager} class.
