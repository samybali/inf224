\doxysubsection{Detailed Description}
Central class that manages all \doxylink{class_multimedia}{Multimedia} objects and Groups. 

The \doxylink{class_manager}{Manager} acts as a factory to create objects (\doxylink{class_photo}{Photo}, \doxylink{class_video}{Video}, \doxylink{class_film}{Film}, \doxylink{class_group}{Group}) and as a database to store them using std::\+map containers. It ensures the consistency of the data (e.\+g., preventing duplicate names) and handles interactions such as displaying, playing, or removing items.
